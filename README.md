Hospedagem de midia publica (video/imagem) para agendamento em redes sociais.

Os arquivos NAO ficam no historico do repo: sao anexados como **release assets**.

Subir:
```bash
gh release upload v1 arquivo.mp4 --repo linnoff88-dev/midia --clobber
```

URL publica resultante:
```
https://github.com/linnoff88-dev/midia/releases/download/v1/arquivo.mp4
```
